智能导航小车系统功能说明

================================================================================
一、项目背景与市场调研
================================================================================

1.1 项目背景
────────────────────────────────────────────────────────────────────────────────

随着智能制造和智慧物流的快速发展，自动导引车(AGV)已成为工业4.0的核心装备之一。
在仓储物流、工厂产线、医院配送、酒店服务等场景中，人工搬运存在效率低、成本高、
易出错等问题，市场对低成本、高可靠性的自主导航小车需求日益增长。

当前AGV导航方案主要有：
  - 磁条导航：成本低、技术成熟，但路径固定、灵活性差
  - 激光SLAM导航：灵活性强，但成本高(单台数万元)、对环境要求高
  - 视觉导航：算法复杂、算力需求大、鲁棒性不足
  - RFID+巡线导航：成本低、可靠性高、适合固定路径场景，是性价比最优方案

本项目采用RFID+红外巡线+超声波避障的组合方案，在保证可靠性的前提下将硬件成本
控制在千元以内，适用于室内固定路径的物品配送场景。


1.2 市场调研
────────────────────────────────────────────────────────────────────────────────

(1) 市场规模
  - 全球AGV市场规模2025年预计超过50亿美元，年复合增长率约15%
  - 中国AGV市场占全球约35%，是最大单一市场
  - 中小型场景(医院、酒店、实验室)对低成本AGV需求增长最快

(2) 竞品分析
  ┌──────────────┬──────────┬──────────┬──────────┬──────────┐
  │  方案         │ 硬件成本  │ 部署难度  │ 路径灵活 │ 可靠性   │
  ├──────────────┼──────────┼──────────┼──────────┼──────────┤
  │ 激光SLAM      │ 2-5万元   │ 高        │ 高       │ 中       │
  │ 视觉导航      │ 1-3万元   │ 高        │ 高       │ 低       │
  │ 二维码导航    │ 0.5-1万元 │ 中        │ 中       │ 中       │
  │ 磁条导航      │ 0.3-0.8万 │ 低        │ 低       │ 高       │
  │ 本项目方案    │ <0.3万元  │ 低        │ 中       │ 高       │
  └──────────────┴──────────┴──────────┴──────────┴──────────┘

(3) 目标场景
  - 医院药品/标本配送：固定走廊路径，需多点配送
  - 酒店物品配送：楼层走廊固定路径，房间号对应RFID卡
  - 工厂产线物料配送：工位间固定路线，按需配送
  - 实验室试剂配送：固定路径，避免人工接触危险品
  - 智慧餐厅传菜：厨房到餐桌固定路径配送


1.3 解决的核心问题
────────────────────────────────────────────────────────────────────────────────

(1) 人工配送效率低
  传统人工搬运需专人往返，人力成本高且效率受限。本小车可7×24小时自主配送，
  单次配送时间可预测，整体效率提升3-5倍。

(2) 配送出错率高
  人工配送易送错房间/工位。本系统通过RFID精确识别路口和房间，自动计算
  最优转向路径，确保物品准确送达指定位置。

(3) 危险环境人工风险
  医院(感染风险)、实验室(化学危险)、工厂(机械伤害)等场景不适合人员频繁出入。
  本小车可替代人工进入这些区域完成配送。

(4) 传统AGV部署成本高
  激光/视觉导航AGV单台数万元，对中小型场景不经济。本方案硬件成本<3000元，
  仅需铺设黑线+贴RFID卡即可部署，适合预算有限的场景。

(5) 系统灵活性不足
  传统磁条导航只能走固定路线无法避障。本系统加入超声波避障，遇到障碍物
  自动绕行后回归路线，兼顾了可靠性与灵活性。


1.4 已实现的功能
────────────────────────────────────────────────────────────────────────────────

  [1] RFID自主导航
      - 读取路口卡自动计算转向方向（左转/右转/直行/掉头）
      - 识别房间卡到达指定目标房间
      - 到达目标后自动掉头返航，回到起点停车

  [2] 红外巡线
      - 8路红外传感器实时检测黑线位置
      - PID闭环控制，平滑跟随黑线行驶
      - 参数(Kp/Ki/Kd/速度)可通过蓝牙在线调节

  [3] 超声波避障
      - 前方障碍物检测（可调距离阈值）
      - 舵机转向测量左/前/右三方向距离
      - 自动选择最优绕行方向，麦轮平移绕过障碍物
      - 绕行后自动回归黑线继续巡线

  [4] 语音控制
      - 语音指令指定目标房间（1-5号）
      - 语音指令触发返航
      - 导航执行中屏蔽新指令，防止冲突

  [5] 蓝牙调参
      - 手机蓝牙实时调整10项运行参数
      - 无需重新烧录固件，现场调试

  [6] LCD实时监控
      - 显示编码器、电压、距离、卡片、方位、导航状态等
      - 方便调试和演示

  [7] 多任务实时协作
      - FreeRTOS 7个任务并发运行
      - 信号量+互斥量保证电机访问安全
      - RFID转向优先级最高，避障次之，巡线最低


================================================================================
二、系统概述
================================================================================

本系统基于STM32F407微控制器，采用FreeRTOS实时操作系统，实现RFID导航、红外巡线、
超声波避障、语音控制、蓝牙调参等功能。小车可在铺设黑线的地图上自主导航至目标房间，
完成配送后自动返航。

系统架构：
  语音模块(SU-03T) ──→ STM32F407 ──→ 麦克纳姆轮电机
  蓝牙模块(HC-05)  ──→  FreeRTOS  ──→ 舵机(超声波转向)
  RFID模块(RC522)  ──→  多任务协作 ──→ 红外巡线模块
  超声波(HC-SR04)  ──→             ──→ LCD显示屏


================================================================================
二、硬件模块
================================================================================

1. 主控：STM32F407，168MHz，运行FreeRTOS
2. 电机驱动：I2C通信闭环编码电机控制板，4个JGB编码电机
3. 运动平台：麦克纳姆轮，支持全向移动（前进/后退/左移/右移/旋转）
4. 巡线模块：8路红外传感器(I2C2通信)，检测黑线位置
5. RFID模块：RC522(SPI1通信)，读取路口卡和房间卡
6. 超声波模块：HC-SR04(TIM5输入捕获)，测距范围2-400cm
7. 舵机：TIM4 PWM控制，0-180度旋转，驱动超声波转向
8. 语音模块：SU-03T(UART2 DMA接收)，语音识别控制
9. 蓝牙模块：HC-05(UART1 DMA接收)，参数调试
10. 显示屏：1.54寸SPI LCD，实时显示系统状态

================================================================================
四、核心功能详解
================================================================================

【1】RFID导航系统
────────────────────────────────────────────────────────────────────────────────

卡片类型：
  路口卡：存储各方向房间号，格式如"N3S0W2E1"
          N=北 S=南 W=西 E=东，数字为该方向的房间号
  房间卡：纯数字，如"3"，表示房间编号

导航状态机：
  NAV_IDLE(0)    → 空闲/停车，等待指令
  NAV_GOING(1)   → 前往目标房间
  NAV_RETURNING(2) → 返航中

方向系统：
  turn_current_dir 表示小车"来的方向"
  DIR_N(0x01)=北 DIR_S(0x02)=南 DIR_W(0x03)=西 DIR_E(0x04)=东
  小车初始从南方出发(DIR_S)，面朝北方

转向计算：
  根据当前方向和目标房间所在方向，计算转向动作
  TURN_STRAIGHT(0x00) → 直行
  TURN_LEFT(0x01)    → 左转90度
  TURN_RIGHT(0x02)   → 右转90度
  TURN_UTURN(0x03)   → 掉头180度
  TURN_ERROR(0xFF)   → 未找到目标

转向执行：
  使用编码器闭环控制转向角度
  左转/右转：目标编码器值 g_turn_encoder_90（默认1000）
  掉头：目标编码器值 g_turn_encoder_180（默认2000）
  超时保护：5秒未达目标编码器值则强制停止

返航逻辑：
  到达目标房间后自动掉头，nav_state切换为NAV_RETURNING
  每个路口卡调用Turn_CalculateReturn()计算返回南方的转向
  到达起点（房间号0）后停车


【2】红外巡线系统
────────────────────────────────────────────────────────────────────────────────

传感器布局（从左到右）：x1 x2 x3 x4 x5 x6 x7 x8
  0 = 检测到黑线，1 = 白底

偏差计算：
  x4+x5黑线 → err=0  （居中）
  仅x4黑线  → err=-1 （偏左一点）
  仅x5黑线  → err=1  （偏右一点）
  x3黑线    → err=-2 （偏左较多）
  x6黑线    → err=2  （偏右较多）
  x2黑线    → err=-3 （偏左很多）
  x7黑线    → err=3  （偏右很多）
  x1黑线    → err=-5 （极左）
  x8黑线    → err=5  （极右）

PID控制：
  位置式PID：输出 = Kp×误差 + Ki×积分 + Kd×微分
  默认参数：Kp=8, Ki=0, Kd=2
  巡线速度：g_ir_speed=80（范围-100~+100）

电机输出：
  Motion_Ctrl(g_ir_speed, 0, pid_output, 0)
  Vx=前进速度, W=旋转量（PID输出）

异常处理：
  全白(0个黑线)或过多(>=6个黑线)时停车，返回1
  irtracking_Task收到返回1时执行直行寻找黑线


【3】超声波避障系统
────────────────────────────────────────────────────────────────────────────────

避障状态机：
  AVOID_NORMAL       → 正常巡线，检测前方障碍物
  AVOID_CHECK_FRONT  → 舵机转正(90度)，测前方距离
  AVOID_CHECK_LEFT   → 舵机转左(180度)，测左侧距离
  AVOID_CHECK_RIGHT  → 舵机转右(0度)，测右侧距离
  AVOID_DECIDE       → 三方向测完，选择绕行方向
  AVOID_TRANSLATE_OUT → 麦轮平移出黑线
  AVOID_FORWARD      → 前进绕过障碍物
  AVOID_FORWARD_EXTRA → 额外前进一段距离确保绕过
  AVOID_TRANSLATE_BACK → 平移回黑线上
  AVOID_ABORT        → RFID转向中止避障

绕行策略：
  1. 检测到障碍物(<20cm)后停车
  2. 舵机依次转向0度/90度/180度测量三方向距离
  3. 选择空间最大的方向平移出线
  4. 前进绕过障碍物（前方距离>20cm后额外前进200编码器值）
  5. 反向平移回黑线
  6. 释放信号量，恢复巡线

障碍物判定距离：g_obstacle_distance=20cm
平移编码器目标：g_translate_encoder_target=200
额外前进编码器：g_forward_extra_encoder=200


【4】语音控制系统
────────────────────────────────────────────────────────────────────────────────

模块：SU-03T语音识别模块，UART2通信(9600bps)

支持的语音指令：
  房间1~5 → 导航至对应房间
  返航    → 返回起点

指令处理逻辑：
  NAV_GOING状态下拒绝新指令（防止中途更改目标）
  NAV_IDLE/NAV_RETURNING状态下可接收新指令
  调用Turn_GoRoom(room_num)设置目标并启动导航


【5】蓝牙调参系统
────────────────────────────────────────────────────────────────────────────────

模块：HC-05蓝牙模块，UART1通信(9600bps)

数据格式：[slider,名称,值]

可调参数：
  Turn90           → 90度转向编码器值（默认1000）
  Turn180          → 180度转向编码器值（默认2000）
  TurnStraight     → 直行编码器值（默认50）
  TranslateTarget  → 避障平移编码器目标（默认200）
  ObstacleDist     → 障碍物判定距离cm（默认20）
  ForwardExtra     → 避障额外前进编码器值（默认200）
  IRSpeed          → 巡线速度（默认80）
  IRKp             → PID比例系数（默认8）
  IRKi             → PID积分系数（默认0）
  IRKd             → PID微分系数（默认2）


【6】LCD显示系统
────────────────────────────────────────────────────────────────────────────────

显示内容：
  第1行：编码器值
  第2行：电池电压(mV)
  第3行：超声波距离(cm)
  第4行：红外传感器状态
  第5行：RFID卡片内容
  第6行：当前方位(North/South/West/East)
  第7行：目标房间号
  第8行：导航状态(Idle/Going/Return)
  第9行：转向方向(Straight/Left/Right/U-Turn/Error)
  第10行：蓝牙参数值


================================================================================
五、任务协作与同步机制
================================================================================

信号量xAvoidSemaphore协调三个任务的电机访问权：

  巡线任务(irtracking_Task)：
    - 非阻塞获取信号量，成功则执行巡线，失败则跳过
    - 每次巡线周期(20ms)获取-释放一次

  避障任务(Avoidance_Task)：
    - 阻塞获取信号量，持有期间巡线任务自动停止
    - 避障完成后释放信号量

  RFID导航任务(car_walking)：
    - 转向时阻塞获取信号量(超时2秒)
    - 转向期间设nav_state=NAV_IDLE，避障任务检测后进入ABORT释放信号量
    - 转向完成后释放信号量，恢复nav_state

优先级关系：RFID转向 > 避障 > 巡线
  RFID识别到卡片时，nav_state=NAV_IDLE导致避障中止，确保转向不被干扰


================================================================================
六、麦克纳姆轮运动学
================================================================================

电机布局：
  m1(右前)  m2(左前)
  m3(右后)  m4(左后)

逆运动学公式：
  m1 = -W + Vy + Vx    （右前）
  m2 =  W + Vy + Vx    （左前）
  m3 = -W - Vy + Vx    （右后）
  m4 =  W - Vy + Vx    （左后）

参数说明：
  Vx：前进速度（正=前进）
  Vy：横移速度（正=左移）
  W ：旋转量（正=逆时针/左转）
  Vz：附加速度（未使用）

运动示例：
  前进：Motion_Ctrl(80, 0, 0, 0)
  左移：Motion_Ctrl(0, 60, 0, 0)
  右移：Motion_Ctrl(0, -60, 0, 0)
  左转：Motor_Set_Speed({60,-60,60,-60})
  右转：Motor_Set_Speed({-60,60,-60,60})


================================================================================
七、完整工作流程
================================================================================

1. 上电初始化
   → 外设初始化(I2C/SPI/UART/TIM)
   → 电机/超声波/舵机/RC522初始化
   → FreeRTOS任务创建
   → 小车处于NAV_IDLE状态

2. 语音/蓝牙下达指令
   → 设置目标房间号，nav_state=NAV_GOING

3. 巡线前进
   → 红外传感器检测黑线，PID控制跟随
   → 超声波实时监测前方障碍物

4. 遇到路口卡(RFID)
   → 停车 → 读取卡片 → 解析方向房间数据
   → 计算转向动作 → 执行转向 → 恢复巡线

5. 遇到障碍物
   → 停车 → 舵机测三方向距离 → 选择绕行方向
   → 平移出线 → 前进绕过 → 平移回线 → 恢复巡线

6. 到达目标房间
   → 停车5秒 → 自动掉头 → nav_state=NAV_RETURNING

7. 返航
   → 路口卡自动计算返回方向 → 巡线返回

8. 到达起点
   → 停车 → nav_state=NAV_IDLE → 等待下一次指令

================================================================================
九、系统创新点
================================================================================

1. RFID+巡线+避障三模融合导航
   传统巡线小车只能走固定路线，遇障即停。本系统在巡线基础上加入RFID路口决策
   和超声波避障绕行，实现了"巡线为主、RFID决策、避障绕行"的三层导航架构，
   兼顾了路径可靠性和环境适应性。

2. 基于方向编码的通用转向算法
   设计了方向编码系统(DIR_N/S/W/E)和转向计算算法(Turn_CalculateTurn)，只需
   在RFID卡中写入各方向房间号(如"N3S0W2E1")，小车即可自动计算左转/右转/直行/
   掉头，无需为每条路线单独编程，地图变更只需更换RFID卡内容。

3. 麦克纳姆轮避障平移回归
   利用麦轮全向移动特性，避障时横向平移出黑线、前进绕过、再平移回黑线，
   相比传统差速轮需要后退绕行，效率更高、路径更短。

4. 多任务优先级抢占式协作
   基于FreeRTOS信号量机制，实现RFID转向>避障>巡线的优先级体系：
   - 巡线非阻塞获取信号量，不影响其他任务
   - 避障阻塞获取信号量，持有期间巡线自动暂停
   - RFID转向通过nav_state强制避障中止，确保转向不被干扰

5. 蓝牙在线调参，无需重烧固件
   10项关键参数(转向编码器值/PID参数/避障距离/巡线速度等)均可通过手机蓝牙
   实时调整，大幅缩短现场调试时间，从传统的"改代码→编译→烧录→测试"缩短为
   "手机滑动→即时生效"。

6. 语音+蓝牙双通道人机交互
   语音控制适合远距离下达指令，蓝牙调参适合精细调试，两种交互方式互补，
   适应不同使用场景。


================================================================================
十、技术难点与解决方案
================================================================================

难点1：多任务并发下的电机访问冲突
────────────────────────────────────────────────────────────────────────────────
  问题：巡线、避障、转向三个任务都需要控制电机，并发访问会导致指令冲突，
        小车动作混乱。

  解决：设计二值信号量xAvoidSemaphore作为电机访问权令牌：
        - 巡线任务非阻塞获取，获取失败则跳过（不阻塞其他任务）
        - 避障/转向任务阻塞获取，确保操作完整性
        - nav_state状态变量作为全局协调信号，RFID转向时设NAV_IDLE
          触发避障ABORT，实现优先级抢占

难点2：RFID卡片重复读取问题
────────────────────────────────────────────────────────────────────────────────
  问题：小车停在RFID卡上方时会反复读取同一张卡，导致重复转向。

  解决：记录上次读取的卡片UID，相同UID的卡片直接跳过，只有新卡片才处理。
        小车离开卡片范围后last_uid清零，允许再次读取。

难点3：转向角度精确控制
────────────────────────────────────────────────────────────────────────────────
  问题：麦轮原地转向时，仅靠延时控制角度精度差，电池电压变化也会影响转速。

  解决：采用编码器闭环控制，累计4个电机编码器平均值达到目标值时停止。
        设置5秒超时保护，防止编码器异常导致无限旋转。
        90度和180度转向分别使用不同编码器目标值，通过蓝牙可现场微调。

难点4：避障后回归黑线
────────────────────────────────────────────────────────────────────────────────
  问题：绕过障碍物后如何精确回到黑线上继续巡线。

  解决：记录平移出线的编码器值(translate_encoder)，绕行后反向平移相同编码器值。
        利用麦轮横移特性，出线和回线使用相同距离，保证回到黑线位置。

难点5：巡线PID参数整定
────────────────────────────────────────────────────────────────────────────────
  问题：不同地面、不同速度下PID参数需要不同，传统方式需反复改代码烧录。

  解决：蓝牙在线调参，Kp/Ki/Kd/速度均可实时修改，边跑边调，快速找到最优参数。

难点6：路口转向方向判断
────────────────────────────────────────────────────────────────────────────────
  问题：小车到达路口后需要根据目标房间判断左转/右转/直行/掉头，方向逻辑容易出错。

  解决：设计方向编码系统，turn_current_dir表示"来的方向"，通过Turn_CalculateTurn()
        算法自动计算转向动作，Turn_UpdateDirection()更新方向状态。
        算法经过16种方向组合穷举验证，确保所有情况判断正确。

十二、未来展望与改进方向
================================================================================

1. 导航能力提升
   - 增加多目标点配送：支持一次出发配送多个房间，优化路径顺序
   - 增加RFID卡写入功能：通过蓝牙远程修改路口卡内容，无需物理换卡
   - 增加地图记忆功能：首次走过后记录路径，支持无RFID区域导航

2. 感知能力增强
   - 增加多路超声波或激光测距：实现前方扇形区域障碍物检测，替代舵机转向测距
   - 增加红外避障：侧面障碍物检测，防止平移时碰撞
   - 增加摄像头：视觉识别路口标志，减少对RFID卡的依赖

3. 交互体验优化
   - 增加OLED/触摸屏：替代当前LCD，显示更丰富的交互界面
   - 增加手机APP：图形化界面控制小车，替代当前蓝牙文本指令
   - 增加语音播报：小车到达房间后语音提示"已到达X号房间"

4. 系统可靠性
   - 增加电量检测与低电量自动返航：防止中途断电
   - 增加看门狗：异常时自动复位恢复
   - 增加编码器断线检测：电机故障时及时停车报警

5. 扩展应用
   - 增加顶层载物平台：实现实际物品配送
   - 增加多车协作：多台小车协同工作，避免路径冲突
   - 增加云端调度：通过WiFi连接服务器，实现远程任务分配和状态监控
